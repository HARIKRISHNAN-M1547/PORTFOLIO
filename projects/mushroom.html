AUTOMATEDMUSHROOMCULTIVATION SYSTEM

A closed-loop controller that keeps an oyster mushroom chamber at the right humidity, fresh air and light, without anyone watching it.

OverviewThe problem and the solution

The problem. Oyster mushrooms need 85–95% humidity, about 18–24 °C and CO₂ kept below roughly 1000 ppm. Doing this by hand means checking and adjusting misting, ventilation and light all day, and small lapses lead to poor yield, contamination or deformed fruit.

The solution. A closed-loop controller built on an ESP32 reads temperature, humidity and (optionally) CO₂, and switches a humidifier, an exhaust fan and a grow light through a relay module to hold the chamber in range.

FeaturesWhat makes the controller reliable

Automated humidity control

Hysteresis (87% ON, 92% OFF) avoids relay chatter. A short humidifier burst after each ventilation cycle stops the fan from undermining humidity.

Fresh-air exchange

CO₂-driven fan control when an MH-Z19B is fitted, with a graceful fallback to a timed cycle when it isn't.

Temperature-assisted ventilation

The fan is forced on above 24 °C, whatever the CO₂ state, as a simple cooling assist.

Scheduled lighting

A Wi-Fi/NTP-based 12-hour photoperiod that holds across power cycles without a dedicated RTC module.

Non-blocking loop

millis()-based timing keeps sensor reads, relay logic and the light schedule responsive in a single loop.

Modular and tunable

CO₂ sensing is optional, and setpoints, pins and intervals are named constants for quick recalibration.

/*
  Automated Mushroom Cultivation Environmental Controller
  Target: Oyster mushroom, fruiting stage, small grow tent
  Board: ESP32

  Sensors expected:
    - DHT22 (or swap in SHT31 via I2C) for temp/humidity
    - MH-Z19B CO2 sensor (UART) - optional but recommended for oyster FAE

  Actuators (via 4-channel relay module, active LOW typical):
    - Relay 1: Humidifier / ultrasonic mist maker
    - Relay 2: Exhaust fan (fresh air exchange)
    - Relay 3: Grow light
    - Relay 4: spare (e.g. circulation fan)

  Control strategy:
    - Humidity and fan are both hysteresis-controlled (not simple thresholds)
      to stop relay chatter right at the setpoint.
    - The fan is prioritized by CO2 when a CO2 sensor is present, and falls
      back to a timed FAE cycle (X minutes every hour) when it isn't.
    - After every fan-driven FAE cycle, the humidifier is nudged on for a
      short burst, since ventilation dumps humidity - this stops the two
      loops from fighting each other.
    - Light runs on a WiFi/NTP-based daily schedule so it holds correctly
      even after a reboot (no RTC module required).

  Wire the relay module's IN pins to the GPIOs below. Most cheap relay
  boards are ACTIVE LOW (LOW = relay energized) - verify yours with a
  multimeter before wiring mains-voltage devices, and put the humidifier/
  fan/light on the LOAD side of the relay, not the ESP32 itself.
*/

#include <DHT.h>
#include <WiFi.h>
#include <time.h>

// ---------- Pin map ----------
#define DHTPIN 4
#define DHTTYPE DHT22

#define RELAY_HUMID 26   // humidifier
#define RELAY_FAN   27   // exhaust fan
#define RELAY_LIGHT 14   // grow light
#define RELAY_SPARE 12   // circulation fan / spare

// If you have an MH-Z19B CO2 sensor on UART2 (RX=16, TX=17), set this true.
#define HAS_CO2_SENSOR false

#if HAS_CO2_SENSOR
  #include <MHZ19.h>
  HardwareSerial co2Serial(2);
  MHZ19 mhz19;
#endif

DHT dht(DHTPIN, DHTTYPE);

// ---------- WiFi (for NTP-based light schedule) ----------
const char* WIFI_SSID     = "YOUR_WIFI_SSID";
const char* WIFI_PASSWORD = "YOUR_WIFI_PASSWORD";
const char* NTP_SERVER    = "pool.ntp.org";
const long  GMT_OFFSET_SEC = 0;   // set to your timezone offset in seconds
const int   DST_OFFSET_SEC = 0;

// ---------- Setpoints (oyster mushroom, fruiting) ----------
const float HUMIDITY_LOW  = 87.0;  // humidifier turns ON below this
const float HUMIDITY_HIGH = 92.0;  // humidifier turns OFF above this
const float TEMP_HIGH     = 24.0;  // fan assists cooling above this
const int   CO2_HIGH_PPM  = 1000;  // fan turns ON above this (if CO2 sensor present)
const int   CO2_LOW_PPM   = 800;   // fan turns OFF below this

// FAE fallback (no CO2 sensor): run fan for FAE_MINUTES every FAE_INTERVAL_MIN
const unsigned long FAE_INTERVAL_MIN = 60;
const unsigned long FAE_MINUTES      = 5;

const int LIGHT_ON_HOUR  = 8;    // 24h clock
const int LIGHT_OFF_HOUR = 20;   // 12h photoperiod

const unsigned long SENSOR_READ_INTERVAL_MS = 10000;  // read every 10s
const unsigned long POST_FAE_HUMID_BURST_MS = 60000;  // 1 min humidifier burst after FAE

// ---------- State ----------
unsigned long lastSensorRead = 0;
unsigned long lastFaeStart   = 0;
unsigned long faeStartedAt   = 0;
unsigned long humidBurstUntil = 0;

bool fanOn   = false;
bool humidOn = false;
bool lightOn = false;

void setRelay(int pin, bool on) {
  // most relay boards are active-LOW; flip this if yours is active-HIGH
  digitalWrite(pin, on ? LOW : HIGH);
}

void setup() {
  Serial.begin(115200);
  dht.begin();

  pinMode(RELAY_HUMID, OUTPUT);
  pinMode(RELAY_FAN, OUTPUT);
  pinMode(RELAY_LIGHT, OUTPUT);
  pinMode(RELAY_SPARE, OUTPUT);
  setRelay(RELAY_HUMID, false);
  setRelay(RELAY_FAN, false);
  setRelay(RELAY_LIGHT, false);
  setRelay(RELAY_SPARE, false);

  #if HAS_CO2_SENSOR
    co2Serial.begin(9600, SERIAL_8N1, 16, 17);
    mhz19.begin(co2Serial);
    mhz19.autoCalibration(false);  // manual calibration recommended for grow tents
  #endif

  WiFi.begin(WIFI_SSID, WIFI_PASSWORD);
  Serial.print("Connecting to WiFi");
  unsigned long start = millis();
  while (WiFi.status() != WL_CONNECTED && millis() - start < 15000) {
    delay(500);
    Serial.print(".");
  }
  if (WiFi.status() == WL_CONNECTED) {
    Serial.println("\nWiFi connected.");
    configTime(GMT_OFFSET_SEC, DST_OFFSET_SEC, NTP_SERVER);
  } else {
    Serial.println("\nWiFi failed - light schedule will not run until reconnected.");
  }
}

void loop() {
  unsigned long now = millis();

  if (now - lastSensorRead >= SENSOR_READ_INTERVAL_MS) {
    lastSensorRead = now;
    readAndControl();
  }

  controlLightSchedule();
}

void readAndControl() {
  float humidity = dht.readHumidity();
  float tempC = dht.readTemperature();

  if (isnan(humidity) || isnan(tempC)) {
    Serial.println("DHT read failed - skipping this cycle.");
    return;
  }

  int co2 = -1;
  #if HAS_CO2_SENSOR
    co2 = mhz19.getCO2();
  #endif

  Serial.printf("RH: %.1f%%  Temp: %.1fC  CO2: %d ppm\n", humidity, tempC, co2);

  // --- Humidity control (hysteresis) ---
  if (humidity < HUMIDITY_LOW) humidOn = true;
  else if (humidity > HUMIDITY_HIGH) humidOn = false;

  // --- Fan control ---
  bool needsFae = false;
  #if HAS_CO2_SENSOR
    if (co2 > CO2_HIGH_PPM) needsFae = true;
    else if (co2 < CO2_LOW_PPM) needsFae = false;
    else needsFae = fanOn;  // hold state inside the band
  #else
    // Timed fallback FAE cycle
    if (millis() - lastFaeStart >= FAE_INTERVAL_MIN * 60000UL) {
      lastFaeStart = millis();
      faeStartedAt = millis();
      needsFae = true;
    } else if (fanOn && millis() - faeStartedAt < FAE_MINUTES * 60000UL) {
      needsFae = true;
    }
  #endif

  // Temperature can also force the fan on regardless of CO2/timer
  if (tempC > TEMP_HIGH) needsFae = true;

  bool faeJustEnded = (fanOn && !needsFae);
  fanOn = needsFae;

  if (faeJustEnded) {
    // ventilation just dropped humidity - force a short humidifier burst
    humidBurstUntil = millis() + POST_FAE_HUMID_BURST_MS;
  }
  if (millis() < humidBurstUntil) humidOn = true;

  setRelay(RELAY_HUMID, humidOn);
  setRelay(RELAY_FAN, fanOn);

  Serial.printf("-> Humidifier: %s  Fan: %s\n", humidOn ? "ON" : "off", fanOn ? "ON" : "off");
}

void controlLightSchedule() {
  struct tm timeinfo;
  if (!getLocalTime(&timeinfo, 100)) return;  // NTP not synced yet

  int hour = timeinfo.tm_hour;
  bool shouldBeOn = (hour >= LIGHT_ON_HOUR && hour < LIGHT_OFF_HOUR);

  if (shouldBeOn != lightOn) {
    lightOn = shouldBeOn;
    setRelay(RELAY_LIGHT, lightOn);
    Serial.printf("Light -> %s\n", lightOn ? "ON" : "off");
  }
}

Set your Wi-Fi name and password at the top, set HAS_CO2_SENSOR to true if you fit an MH-Z19B, and check your relay polarity before connecting mains loads.

TestingExpected results and validation plan

These are design-stage expectations, not measured results. They will be replaced with real data once the build is tested.

Expected results

  • Humidity held in the 85–95% band without rapid relay cycling.
  • CO₂ kept below the 800–1000 ppm band by fresh-air exchange.
  • A 12-hour photoperiod that recovers correctly after a power cycle.
  • Lower water and electricity use than manual or timer-only control.

Validation plan

  • Check relay polarity with a multimeter before any mains load.
  • Bench-test each sensor against a reference hygrometer and thermometer.
  • Run the chamber empty for 24–48 hours to confirm a stable loop.
  • Log relay switching over a full fruiting cycle and widen the hysteresis band if it cycles too often.
